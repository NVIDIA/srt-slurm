# DSight

Before using or changing DSight, read the [DSight guide](../../../docs/dsight.md)
and load the applicable skills from its
[skill index](../../../docs/dsight.md#agent-skills) by reading the linked skill
files. This also applies to analysis of existing reports and preparation of
dashboard views without code changes.

Use [dsight-query](../../../.agents/skills/dsight-query/SKILL.md) for evidence queries and analysis.
Keep query and storage contracts in the
[storage reference](../../../docs/dsight-storage.md), and source-to-UI mappings
in the [data-flow guide](../../../docs/dsight-data-flow.md).
