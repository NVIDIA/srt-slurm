1. GPU collective runtime versions are now confirmed to differ.

All 32 NCCL initialization messages report:
  Raplab: NCCL 2.30.4+cuda13.2
  Hecate: NCCL 2.31.2gr100+0.8.0+cuda13.5

This is stronger runtime evidence than Python package metadata or the
separate torch.cuda.nccl.version() probe. Upstream PyTorch's implementation
returns a version encoded from compile-time NCCL headers, not ncclGetVersion:
https://github.com/pytorch/pytorch/blob/main/torch/csrc/cuda/nccl.cpp
(version() and version_suffix()). The exact private PyTorch fork has not been
inspected; the probe alone should not be treated as runtime verification.
Earlier descriptions of that probe as runtime evidence were too strong.

Hecate's rank metadata already maps /usr/lib/aarch64-linux-gnu/libnccl.so.2.31.2
alongside MPI's UCC components BEFORE the explicit GPU tests. Raplab excludes
ucc/hcoll and has no NCCL mapping at that point. A plausible explanation is
different library loading/symbol resolution after UCC initialization. This
remains an inference: post-NCCL library maps and dependency resolution would
be needed to establish the actual loading chain and Raplab library path.

4. Prioritize library alignment before general NCCL parameter tuning.

First determine and control which NCCL library the GPU backend loads on both
clusters. This is a concrete version/build difference; it is not yet proven
to cause the tail gap. Capture post-NCCL library maps and library hashes.

A focused experiment to test the UCC/loading hypothesis is to rerun Hecate
with the Raplab collective exclusion, retaining NCCL INFO output:

export NCCL_DEBUG=INFO
export NCCL_DEBUG_SUBSYS=INIT,NET,GRAPH
export OMPI_MCA_coll='^ucc,hcoll'
sbatch --nodes=8 --segment=8 --account=coreai_mlperf_inference \
  --partition=batch-xdr --export=ALL,RUN_NCCL=1 \
  configs/cluster-diagnostics.sbatch hecate

Check the NCCL initialization version and pre-GPU loaded libraries in that
run. The experiment can show whether excluding UCC changes runtime selection;
it is not a promised fix and changes MPI collective behavior too. Explicitly
controlling the GPU NCCL library is a cleaner subsequent comparison.

Once runtime versions match, separate host wall time from GPU-event duration
and keep per-rank iteration samples. Only then use individual tuner/algorithm
experiments to identify an execution-path effect. Copying Hecate's channel
counts alone would not reproduce its NCCL build or topology model.
